# Observability Checklist

- [ ] Critical APIs log: method, path, actorId, statusCode, duration
- [ ] Errors include correlation/request id
- [ ] Health endpoint returns app + db status
- [ ] Permission denied events are traceable
- [ ] Important state changes are auditable (operation logs)
- [ ] At least one dashboard/query to inspect recent failures
- [ ] Release notes include known risks and rollback plan
